# Student Grade Management System

A medium-level Java console project demonstrating:
- Classes and objects
- Encapsulation
- ArrayList
- Methods
- switch
- Loops
- Exception handling
- Input validation
- Grade and pass/fail calculation

## Run locally or in GitHub Codespaces

Open a terminal in the project root:

```bash
javac src/Main.java
java -cp src Main
```

## Grade Rules

- 90-100: A+
- 80-89: A
- 70-79: B
- 60-69: C
- 50-59: D
- Below 50: F

Pass mark: 40

## GitHub

Upload the complete `StudentGradeSystem` folder to a GitHub repository,
then create a Codespace from that repository.

## Codespaces

In the Codespaces terminal:

```bash
javac src/Main.java
```
